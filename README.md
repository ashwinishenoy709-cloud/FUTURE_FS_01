# Ashwini Shenoy — Personal Portfolio

A personal portfolio website showcasing my skills, projects, education, certifications, and experience as a Computer Science Engineering student.

## About

This portfolio highlights my work in software development, web development, and cybersecurity. It provides an overview of my technical skills, featured projects, education, certifications, and ways to get in touch.

## Features

- Responsive portfolio design
- Light and dark mode
- Interactive project showcase
- Resume viewing and download
- Certificate viewing
- Contact form
- Responsive navigation for desktop and mobile

## Tech Stack

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- Vite
- Supabase

## Pages

- **Home** — Introduction, about, skills, featured projects, and education
- **Projects** — Detailed project showcase
- **Blog** — Blog posts and technical content
- **Resume** — Resume, certifications, and achievements
- **Contact** — Contact form and professional links

## Getting Started

Clone the repository:

git clone https://github.com/ashwinishenoy709-cloud/FUTURE_FS_01.git

Navigate to the project:

cd FUTURE_FS_01

Install dependencies:

npm install

Start the development server:

npm run dev

## Production Build

npm run build
