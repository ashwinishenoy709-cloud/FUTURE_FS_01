# Ashwini Shenoy — Personal Portfolio

A personal portfolio website showcasing my education, technical skills, projects, achievements, experience, and professional journey.

## Tech Stack

- React
- TypeScript
- TanStack Router
- Tailwind CSS
- Supabase
- Vite

## Features

- Responsive personal portfolio
- About and education section
- Technical skills
- Projects showcase
- Resume
- Certifications and achievements
- Blog
- Contact form
- Dark/light theme
- SEO-friendly pages
